## 1. 产品定义

### 1.1 一句话

提供一系列名为「**{宝可梦名}之力**」的武器。玩家**热键栏持握**时：外观变为该宝可梦、获得**持握被动**与**技能 1 / 技能 2 / 能量大招**、以及按属性结算的情境弱加成；**取消持握后立刻失去**外观与全部相关效果。

### 1.2 设计本质

- 这是**换皮武器**，不是可独立操控的宝可梦实体。
- 战斗 = **技能 1/2 + 能量大招** + **持握被动** + **仅变身生效的饰品**。
- 数值对齐灾厄流程，避免同阶段落后。
- 随世界进度**进化**（物品直接替换为下一形态），使各阶段都有刚变强的选项。

### 1.3 第一版明确不做

- 完整图鉴养成系统
- PvP 平衡 / 玩家之间的属性克制
- 给原版或灾厄敌人标注「宝可梦属性」并做完整克制表
- 第二套完整体型的角色控制器
- 无冷却、无限制的永久穿墙
- **自制特效贴图 / 额外 FX 图片资源**（见 §1.5）

### 1.4 宝可梦外观资源

- Overlay / 物品图标等**宝可梦立绘与精灵图**可从神奇宝贝百科全国图鉴列表自行获取并纳入模组：  
  https://wiki.52poke.com/wiki/宝可梦列表（按全国图鉴编号）
- 获取后按 `FormId` 整理进资源目录；显示名与路径仍须可配置替换。
- 实现 Agent 可按形态名单自行下载对应编号页面中的官方风格精灵图，无需等待策划另供包。

### 1.5 特效（FX）资源与实现约束

- **本版本不提供、也不允许新增**任何专用特效图片文件（无自制 dust 贴图、无自制弹幕序列帧、无自制光效图集）。
- 所有打击、弹幕、天气、穿障、挖掘等**视觉特效**必须：
  1. **复用**原版泰拉瑞亚已有 Dust / Projectile / Gore / 粒子；或  
  2. **复用 / 参考**灾厄（Calamity）已有特效资产与写法；或  
  3. **复用 / 参考**隔壁灾厄大修项目（`CalamityOverhaul`）的特效实现方式（可改逻辑、改组合、改参数，但**不拷贝其玩法内容**，且不引入该模组运行时依赖）。
- 允许：用代码改 FX 的生成频率、颜色、缩放、轨迹、生命周期；用原版/灾厄已有 `TextureAssets` / `ModContent.Request` 指向**已存在**的贴图。
- 禁止：为「更好看」而向仓库加入新的 FX 图片资源。

## 2. 核心规则

### 2.1 持握 = 变身

变身状态由**服务端**根据当前热键栏选中物品判定，并同步给客户端。客户端可预测，冲突以服务端为准。

**进入条件（同时满足）：**

1. 玩家存活  
2. 热键栏当前选中物品为本模「xxx之力」  
3. 物品在热键栏槽位内（不包括鼠标悬空物品、背包未选中格）

**保持：** 开背包、对话、用药、钩爪等 —— 只要选中之力不变。

**退出（条件满足的同一 tick 内清除本模变身效果）：**

- 切换到其他物品 / 空槽  
- 之力被移走、替换或进化替换（若新选中仍是本模之力，则同 tick 进入新形态）  
- 死亡（复活后需重新持握）  
- 本模强制解除效果（若有）

### 2.2 禁止坐骑（硬规则）

**持握任意「xxx之力」期间，完全禁止使用坐骑。**

- 无法召唤 / 骑乘坐骑；已在坐骑上则强制下马。  
- 取消持握后坐骑功能恢复正常。  
- UI / 物品描述需写明此限制。

### 2.3 外观

- 默认方案：隐藏玩家身体与盔甲绘制，在玩家位置绘制**居中 Overlay**（宝可梦贴图）。  
- 每形态至少：待机、移动、跳跃、招式 A、招式 B（后两者可共用帧）。  
- 其他玩家必须看到相同形态；隐身时遵循原版隐身规则。  
- 第一版 Overlay 不吃盔甲染料。  
- 退出变身的同一 tick 必须停止 Overlay，禁止残留。

### 2.4 碰撞

| 级别 | 含义 | 约束 |
|------|------|------|
| A（默认） | 使用原版玩家碰撞 | 新形态默认；M0 只做 A |
| B | 小幅调整宽高 | 每维变化 ≤20% 且绝对增量 ≤8px；**碰撞箱必须小于展示贴图**；联机不稳则降回 A |
| C | 限时穿障 | 禁止把永久碰撞改成穿墙；只允许限时标志 |

**穿障额外限制：**

- 单次 ≤2.0 秒，冷却 ≥8.0 秒  
- 最终时长 = min(基础 + 加成, 2.0s)，饰品不得突破 2.0s  
- 建议穿障基底 1.5s（饰品可加到 2.0）  
- 结束时若卡在实心砖内：传送到最近安全格；否则短暂定身，不因此处死  
- 与 Boss 交战（造成或受到伤害）后 3 秒内不可开启  
- 穿障中不可拾取、开箱、放砖/挖砖  
- 第一版带穿障的形态 ≤2 个

### 2.5 招式与大招（技能 1 / 技能 2 / 能量大招）

- 每只之力具备：**持握被动** + **技能 1**（默认左键）+ **技能 2**（默认右键）+ **大招**（能量满后由 Mod 热键释放）。  
- **被动**在持握该之力期间持续生效（可与 §3 情境弱加成并存；持握被动优先）。  
- **大招**常规不可用；变身期间按形态积攒能量，满条后方可释放。能量按 `FormId` 分存，解除变身暂停积攒。  
- 招式风格可因宝可梦而异（近战、远程、突进、AOE、天气、挖掘、缠绕 DoT 等），但每只都要在至少一类场景里有用。  
- 招式表必须填写：键位冲突等级、联机风险、碰撞级别、是否授予穿障、是否消耗/依赖能量。  
- 详细泰拉适配见 `docs/move-effects.md`。

### 2.6 伤害

使用本模独立伤害类型（如 `HenshinDamage`）。

**计入：** Generic 增伤/暴击/攻速；本模饰品与情境加成；盔甲/饰品上的 Generic 向；作用于 Generic 的药水；旗帜等目标侧修正；灾厄怒气 / 肾上腺素。

**职业专精**（近战/远程/魔法/召唤/盗贼等）：按系数 **k = 0.35** 折算后计入。

**不计入：** 盗贼潜行偷袭类；真近战专用加成（除非该招式标注为真近战并单独验收）；未登记的其他模组加成。

另有每形态系数 `HenshinDamageFactor`（默认 1.0）用于微调。禁止「独立伤害再乘一遍各职业满额」。

**平衡验收：** 相对同阶段对标武器，有效 DPS 落在 80%～120%；极端混搭堆料不超过 130%；须能通关对应阶段内容。

### 2.7 命名

- 显示名：`{宝可梦名}之力`  
- 内部 ID：`Lxx_Fyy`（链/形态），显示名与贴图路径必须可配置替换

## 3. 属性与情境加成

敌人没有「宝可梦属性」。本模**不做**对敌人的属性克制表。

属性只用于：

1. 持握时的通用被动  
2. 招式主题  
3. 共鸣饰品条件  

增益来自**情境**（生物群落、天气、液体、高度、昼夜、自身/目标状态、是否 Boss、周围敌人数等）。不考虑 PvP。

双属性：主属性决定被动框架；副属性最多给 1 个弱加成。

第一版以主流属性为主，允许缺少部分冷门属性（如冰系可留待后续）。

| `BiomeSnow` / `BiomeIce` / `WeatherSnow` | 雪原 / 冰层 / 暴雪或雪场 |

## 4. 进度与进化

### 4.1 进度档 `ProgressStage`（1～12）

`GetProgressStage()` = 当前满足的最大档。形态可用条件：`GetProgressStage() >= 该形态.Stage`。

| 档 | 名称 | 解锁条件（满足任一） |
|---:|------|----------------------|
| 1 | 前期 | 世界创建即解锁 |
| 2 | 史前中段 | 荒漠灾虫 / 克苏鲁之眼 / 蟹叶草 |
| 3 | 史前后段 | 世界恶（原版或灾厄）/ 蜂后 / 骷髅王 |
| 4 | 肉山前 | 史莱姆神 / 鹿角怪（**不含**肉山倒下） |
| 5 | 困难早期 | 困难模式（肉山倒下） |
| 6 | 困难中段 | 冰雪之柱 / 任一机械 Boss / 渊海灾虫 / 硫磺火元素 |
| 7 | 世花档 | 灾厄之影 / 世纪之花 |
| 8 | 月前 | 石巨人 / 利维坦 / 星体史莱姆 / 瘟疫使者 / 毁灭者等月前灾厄 Boss / 邪教徒 |
| 9 | 月后早期 | 月亮领主 |
| 10 | 亵渎档 | 亵渎天神 / 痴愚金龙 / 亵渎守卫 |
| 11 | 神吞档 | 幽花 / 神明吞噬者 / 老公爵 |
| 12 | 终局 | 犽戎 / 星流巨械 / 至尊灾厄 |

具体 `Downed*` 字段名以当前灾厄 API 为准，用适配层映射；老公爵对应 `downedBoomerDuke`。

### 4.2 每档供给

- 每个进度档「新登场」（新获得或本档进化到位）数量为 **1～3**（推荐 2，禁止 ≥4）。  
- 同档多只为**互竞**关系（风格不同，让玩家选），不是强制互补套装。  
- 若某档为 3 只，须在内容表注明分化维度（输出 / 机动 / 探索）。

### 4.3 进化

- 触发：击败指定 Boss、完成事件、或达到对应 `ProgressStage`。  
- 形式：物品**直接替换**为下一形态（默认不返还材料）。  
- 战斗向：在对应档位进化，匹配当前强度。  
- 功能向（飞行、挖掘、水下等）：可跨多档缓慢进化。

**相邻形态进度差限制：**

- 战斗向：Stage 差 ≤3；若差 =3，旧形态在中间档仍须通过对标 DPS 抽检  
- 功能向：Stage 差 ≤6  

**替换范围：**

| 位置 | 自动进化 |
|------|----------|
| 背包、热键栏、鼠标悬空物品 | 是 |
| 银行、保险箱、世界箱子、地上掉落、商店 | 否（可手动进化） |

流程：服务端校验 → 玩家确认 UI → 替换物品类型（**继承重铸前缀与收藏**）→ 同步。失败则不改物品。

### 4.4 开局御三家

世界创建后（或玩家首次进入该世界时），发放：

- **小火龙之力**  
- **杰尼龟之力**  
- **妙蛙种子之力**  

各 1 件。玩家同时拥有三件，但同一时间只能持握一件并变身。

### 4.5 第一版体量

约 **16～17 条进化链**、**约 35～36 个形态**（含后期传说/幻之宝可梦）。

## 5. 获取途径

可并存：开局发放、Boss 掉落、合成、生物群落探索、事件、钓鱼、商店。

同档互竞之力的获取难度应大致同阶。功能向须在需要该能力的阶段已可获得或可进化到位。

## 6. 饰品

参考宝可梦携带物概念，数值随灾厄阶段成长。

| 种类 | 生效条件 |
|------|----------|
| 通用变身饰品 | 持握**任意**之力 |
| 共鸣饰品 | 持握**指定属性或指定进化链**的之力 |

- **未持握之力时：本模效果全部不生效**，但仍占用饰品栏（含灾厄额外饰品栏）。  
- 第一版禁止「未变身也有强力隐藏效果」。  
- 未生效时描述需标明：`【仅变身生效·当前未生效】`。

## 7. 天气与地形

### 7.1 天气

招式通过服务端生成**天气场**（中心、半径、持续、标签），默认不永久改写世界降雨。  
伤害与潮湿等判定只读服务端场状态。不取消灾厄自身天气事件。  

默认占位：半径 24 格、持续 15 秒、同类冷却 30 秒。  
全球天气仅允许后期（档 ≥9）且招式明确标注，持续 ≤60 秒。

### 7.2 地形改造

| 进度 | 半径上限 | 频率上限 | 可逆性 |
|------|----------|----------|--------|
| 档 ≤6 | 3 格 | ≤8 砖/秒，≤60 砖/分 | 临时砖约 10 秒还原，或只挖不放 |
| 档 7～9 | 6 格 | ≤15 / ≤120 | 默认可持久 |
| 档 ≥10 | 12 格 | ≤30 / ≤300 | 持久 |

任何阶段禁止破坏：箱子、祭坛、生命水晶、床、TileEntity、关键机关等（黑名单由实现维护）。超预算则拒绝并提示。

## 8. 联机

必须保证主机与客户端一致：变身形态、招式伤害、Buff、进化结果、天气场的伤害相关部分、地形实际变更。

最小同步包：`SyncForm`、`SyncPhasing`、`SyncWeatherField`、`RequestEvolve` / `ApplyEvolve`、`TerrainBudgetReject`。

## 12. 技术约束

1. 变身用可清理的玩家标志 / Buff；退出时只清除本模授予的效果，不误删原版或灾厄增益。  
2. 切换另一种之力时：先完整退出，再进入。  
3. 水下呼吸、熔岩免疫等优先用 `ModPlayer` 标志模拟。  
4. 进化与进度校验必须在服务端完成。  
5. 伤害按第 2.6 节接入灾厄，并做职业叠乘回归测试。  
6. 天气场与改地形必须服务端权威。  
7. 显示名与资源路径可热替换，避免写死无法换皮。  
8. 依赖版本：与当前稳定灾厄所要求的 tModLoader 一致；开工时在工程内钉死版本号。  
9. 特效资产遵守 §1.5；宝可梦外观资源遵守 §1.4。

## 14. 验收清单

1. 持握之力：外观、被动、技能1/2、能量大招、变身饰品同时生效；坐骑不可用。  
2. 取消持握：上述本模效果同 tick 消失；坐骑恢复可用。  
3. 开局可获得御三家三件之力。  
4. 进化符合替换范围与前缀继承。  
5. 每进度档有 1～3 个新登场；同档互竞可感知。  
6. 持握被动与情境加成按第 2.5 / 3 节工作；不存在「按敌人宝可梦属性克制」。  
7. 后期存在超梦、洛奇亚、烈空坐等更强传说向之力。  
8. 联机下形态、能量与伤害无明显分歧。  
9. 大范围改地形仅后期；穿障（若有形态授予）不越 2.0 秒且不卡墙。  
10. DPS 落在对标区间内。  
11. 仓库中**无**为本模新增的专用特效图片；招式观感来自原版/灾厄/大修复用或改参。  
12. 变身 Overlay 使用的宝可梦图来自约定图鉴来源（或可替换路径），而非自制特效图集。  
13. 物品描述含获取/进化条件；进度档提升有提示（史莱姆王 ≠ 史莱姆神）。
