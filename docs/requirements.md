## 1. 产品定义

### 1.1 一句话

提供一系列名为「**{宝可梦名}之力**」的武器。玩家**热键栏持握**时：外观变为该宝可梦、获得**持握被动**与**技能 1 / 技能 2 / 能量大招**、以及按属性结算的生存/机动（§3.2）；**取消持握后立刻失去**外观与全部相关效果。

### 1.2 设计本质

- 这是**换皮武器**，不是可独立操控的宝可梦实体。
- 战斗 = **技能 1/2 + 能量大招** + **持握被动** + **仅变身生效的饰品**。
- 数值对齐灾厄流程，避免同阶段落后。
- 随世界进度与**物品等级**共同满足条件时**进化**（物品直接替换为下一形态）；等级在段内**明显**抬攻防，进化提供新形态与新技能。
- 每件「xxx之力」有独立的**等级 / 经验**（物品实例，非账号全局）；数值细节见 §4.6 与 `docs/balance-stats.md`。

### 1.3 第一版明确不做

- 图鉴 UI / 收集图鉴 / 放生 / 经验分享等完整图鉴养成（**做**每物品等级经验与攻击/防御两维）
- Boss 首杀额外经验、卡顶/满级经验溢出转能量
- PvP 平衡 / 玩家之间的属性克制
- 给原版或灾厄敌人标注「宝可梦属性」并做完整克制表
- 第二套完整体型的角色控制器
- 无冷却、无限制的永久穿墙
- HP / 速度等六维；本模战斗属性仅 **攻击、防御**
- **自制特效贴图 / 额外 FX 图片资源**（见 §1.5）

### 1.4 宝可梦外观资源

- Overlay / 物品图标等**宝可梦立绘与精灵图**可从神奇宝贝百科全国图鉴列表自行获取并纳入模组：  
  https://wiki.52poke.com/wiki/宝可梦列表（按全国图鉴编号）
- 获取后按 `FormId` 整理进资源目录；显示名与路径仍须可配置替换。
- 实现 Agent 可按形态名单自行下载对应编号页面中的官方风格精灵图，无需等待策划另供包。

### 1.5 特效（FX）资源与实现约束

- **本版本不提供、也不允许新增**任何专用特效图片文件（无自制 dust 贴图、无自制弹幕序列帧、无自制光效图集）。
- 所有打击、弹幕等**视觉特效**必须：
  1. **复用**原版泰拉瑞亚已有 Dust / Projectile / Gore / 粒子；或  
  2. **复用 / 参考**灾厄（Calamity）已有特效资产与写法；或  
  3. **复用 / 参考**隔壁灾厄大修项目（`CalamityOverhaul`）的特效实现方式（可改逻辑、改组合、改参数，但**不拷贝其玩法内容**，且不引入该模组运行时依赖）。
- 允许：用代码改 FX 的生成频率、颜色、缩放、轨迹、生命周期；用原版/灾厄已有 `TextureAssets` / `ModContent.Request` 指向**已存在**的贴图。
- 禁止：为「更好看」而向仓库加入新的 FX 图片资源。

## 2. 核心规则

### 2.1 持握 = 变身

变身状态由**服务端**根据当前热键栏选中物品判定，并同步给客户端。客户端可预测，冲突以服务端为准。

**进入条件（同时满足）：**

1. 玩家存活  
2. 热键栏当前选中物品为本模「xxx之力」  
3. 物品在热键栏槽位内（不包括鼠标悬空物品、背包未选中格）

**保持：** 开背包、对话、用药、钩爪等 —— 只要选中之力不变。

**退出（条件满足的同一 tick 内清除本模变身效果）：**

- 切换到其他物品 / 空槽  
- 之力被移走、替换或进化替换（若新选中仍是本模之力，则同 tick 进入新形态）  
- 死亡（复活后需重新持握）  
- 本模强制解除效果（若有）

### 2.2 禁止坐骑（硬规则）

**持握任意「xxx之力」期间，完全禁止使用坐骑。**

- 无法召唤 / 骑乘坐骑；已在坐骑上则强制下马。  
- 取消持握后坐骑功能恢复正常。  
- UI / 物品描述需写明此限制。

### 2.3 外观

- 默认方案：隐藏玩家身体与盔甲绘制，在玩家位置绘制**居中 Overlay**（宝可梦贴图）。  
- 单帧贴图：地面移动时轻微上下浮动，离地微抬，按朝向翻转。  
- 其他玩家必须看到相同形态；隐身时遵循原版隐身规则。  
- Overlay 不吃盔甲染料。  
- 退出变身的同一 tick 必须停止 Overlay，禁止残留。

### 2.4 碰撞

现役形态一律用原版玩家碰撞（代码级别 A）。其它碰撞字段见 §12.1。

### 2.5 招式与大招（技能 1 / 技能 2 / 能量大招）

- 每只之力具备：**持握被动** + **技能 1**（默认左键）+ **技能 2**（默认右键）+ **大招**（能量满后由 Mod 热键释放）。  
- **被动**在持握该之力期间持续生效（可与 §3 属性生存/机动并存；持握被动优先）。  
- **大招**常规不可用；变身期间按形态积攒能量，满条后方可释放。能量按 `FormId` 分存，解除变身暂停积攒。  
- **能量池（v1.4）：** 默认 `EnergyMax = 1000`（形态可覆写）。大招一次耗尽至 `UltRetainFraction`（默认 0；A20=0.20）。  
  - 命中：`EnergyOnHit = 12` × 招式 `EnergyGainFactor` × 饰品修正  
  - 打标次级弹命中：`EnergyOnFragmentHit = 1` × `EnergyGainFactor` × 饰品修正（须 `MarkCrumb`；**现役仅**龙之波动爆炸碎片 620。未打标的 `RetargetAsHenshin` 弹仍走上一行，如污泥毒云）  
  - 击杀：`EnergyOnKill = 55` × `EnergyGainFactor`（打标碎片击杀仍走本条）  
  - 被动：`0.15 / tick`（Boss 附近 ×3）  
  - 大招命中**不**充能  
  - **无**按 tick 的命中 ICD；改为滚动 1 秒窗口内命中+击杀能量合计 **≤ 1000**（软顶，只兜极端连击；被动不受限）  
  - `EnergyGainFactor` 默认：Standard 1.0 / HighFrequency 0.35 / MultiHit 0.25 / WideAoE 0.45 / Ultimate 0  
  - 数值表与异常倍率见 `docs/balance-stats.md`；玩法语义见 `docs/move-effects.md`  
- 招式风格可因宝可梦而异（近战、远程、突进、AOE、缠绕 DoT、地鼠线改地形等）。  
- 招式表填写：键位冲突等级、联机风险、能量依赖。  
- **同一招式名**在不同形态或不同槽位（技能 vs 大招）**允许且应当**使用不同 `DamageMultiplier` / 效果。  
- 详细泰拉适配见 `docs/move-effects.md`；数值预算见 `docs/balance-stats.md`。

### 2.6 伤害

使用本模独立伤害类型（如 `HenshinDamage`）。

**面板伤来源（v1.4）：** 持握之力的 `Item.damage` 取自该物品实例的 **`FinalAttack`**（§4.6：阶段基准 × 等级插值 × 种族攻击修正 × `HenshinDamageFactor`）。**废弃**旧式固定 `StageDamage = 8 + stage * 6` 作为唯一面板。

招式最终弹幕伤再乘该槽 `MoveSpec.DamageMultiplier`。设计招式时必须核算：

`MoveRefRate = (60 / UseTime) * DamageMultiplier * ExpectedHitsPerRelease`

标准技原始公式约为 **3.0**（3 APS）；表中 `0.85～1.15` 是相对该值的**归一化**窗（`MoveRefRate / 3`）。**MoveRefRate 为预算参考而非铁律**。段数同时影响伤害与手感，**优先调单段倍率/充能 Factor，谨慎改段数**。追踪易命中远程可偏低、短距近战高风险可偏高；细则见 `docs/balance-stats.md` §7 与 `.cursor/skills/henshin-moves`。

**计入：** Generic 增伤/暴击/攻速；本模饰品与属性被动幅度（A03）；盔甲/饰品上的 Generic 向；作用于 Generic 的药水；旗帜等目标侧修正；灾厄怒气 / 肾上腺素。

**职业专精**（近战/远程/魔法/召唤/盗贼等）：按系数 **k = 0.35** 折算后计入。

**不计入：** 盗贼潜行偷袭类；真近战专用加成（除非该招式标注为真近战并单独验收）；未登记的其他模组加成。

另有每形态系数 `HenshinDamageFactor`（默认 1.0）用于微调，与种族 `AttackMod` **相乘**。禁止「独立伤害再乘一遍各职业满额」。

**平衡验收：** 相对同阶段对标武器（优先参考灾厄大修比目鱼同进度**有效 DPS** 量级，其次同档灾厄主战武器），有效 DPS 落在 **80%～120%**；极端混搭堆料不超过 130%；须能通关对应阶段内容。抽检优先 ProgressStage **7 / 9 / 12**。

### 2.7 变身防御（v1.4）

变身期间：

1. 从 `player.statDefense` **减去盔甲三槽**（`armor[0..2]`）提供的 `defense` 合计（夹到 ≥0）。  
2. **加上**该物品的 **`FinalDefense`**（§4.6）。  
3. **饰品**提供的防御**保留**；灾厄 DR / 护盾 / 怒气减伤等非 `statDefense` 来源**不改**。  
4. 既有 `IncomingDamageMultiplier` 等本模承伤乘区仍生效。

Tooltip 须说明：形态防御取代盔甲防御；饰品防御仍生效。

### 2.8 命名

- 显示名：`{宝可梦名}之力`  
- 内部 ID：`Lxx_Fyy`（链/形态），显示名与贴图路径必须可配置替换

### 2.9 变身属性面板

开背包时，在**原版 10×5 物品栏右缘**（盔甲头盔上方空隙）显示入口按钮；点击打开只读面板，汇总**当前持握之力**的形态、招式、持握特性、属性生存/机动、战斗加成合计、已装备本模饰品（含未生效原因）与冷却/层数。

- **是：** 本地玩家当前状态的查询 UI。未持握时仍可打开，只提示未变身，并列出已装备本模饰品（不变之石未变身也可生效）。
- **不是：** 图鉴 / 收集列表 / 预览未持握之力 / DPS 估算 / 给敌人标属性。
- 条件特性（猛火、叶绿素等）标注当前是否触发。战斗合计读 `HenshinPlayer` 运行时字段（特性+属性+饰品已混在一起）；面板攻击走 `GetWeaponDamage`（含 Generic / 职业折算 / 灾厄怒气等已进面板的来源，不逐条拆怒气）。
- 不展示未接线管线（穿障开关、天气场、`FormRole`，见 §12.1）。
- 面板打开时可能盖住灾厄额外饰品栏；关掉即可点那些格子。无独立热键（v1）。

## 3. 属性与持握生存/机动

属性用于：持握生存/机动（§3.2）、招式主题与持握被动（猛火/激流等）、共鸣饰品条件。对敌人不做宝可梦属性克制。

双属性：主属性决定被动框架；副属性给一组弱加成（见 §3.2）。

## 4. 进度与进化

### 4.1 进度档 `ProgressStage`（1～12）

`GetProgressStage()` = 当前满足的最大档。形态可用条件：`GetProgressStage() >= 该形态.Stage`。

| 档 | 名称 | 解锁条件（满足任一） |
|---:|------|----------------------|
| 1 | 前期 | 世界创建即解锁 |
| 2 | 史前中段 | 荒漠灾虫 / 克苏鲁之眼 / 蟹叶草 |
| 3 | 史前后段 | 世界恶（原版或灾厄）/ 蜂后 / 骷髅王 |
| 4 | 肉山前 | 史莱姆神 / 鹿角怪（**不含**肉山倒下） |
| 5 | 困难早期 | 困难模式（肉山倒下） |
| 6 | 困难中段 | 冰雪之柱 / 任一机械 Boss / 渊海灾虫 / 硫磺火元素 |
| 7 | 世花档 | 灾厄之影 / 世纪之花 |
| 8 | 月前 | 石巨人 / 利维坦 / 星体史莱姆 / 瘟疫使者 / 毁灭者等月前灾厄 Boss / 邪教徒 |
| 9 | 月后早期 | 月亮领主 |
| 10 | 亵渎档 | 亵渎天神 / 痴愚金龙 / 亵渎守卫 |
| 11 | 神吞档 | 幽花 / 神明吞噬者 / 老公爵 |
| 12 | 终局 | 犽戎 / 星流巨械 / 至尊灾厄 |

具体 `Downed*` 字段名以当前灾厄 API 为准，用适配层映射；老公爵对应 `downedBoomerDuke`。

### 4.2 各档登场

各档登场名单与数量见 §9.2。同档多只为互竞战斗风格。

### 4.3 进化

**触发条件（当且仅当同时满足，缺一不可）：**

1. **世界进度：** `GetProgressStage() >= nextForm.Stage`  
2. **物品等级：** 该之力实例的 `Level >= BandMin[nextForm.Stage]`（等级带见 §4.6 / `docs/balance-stats.md`）

例：小火龙（`L01_F01`，Stage 1）→ 火恐龙（`L01_F02`，Stage 4）：须 `ProgressStage ≥ 4` **且** `Level ≥ 19`（Stage 4 段起点）。仅击败 Boss 抬高进度、但等级仍停在 1～5 段时，**不得**进化。

- 形式：物品**直接替换**为下一形态（默认不返还材料）。  
- **继承：** 重铸前缀、收藏标志、以及 **`Level` / `Xp` 完整继承**到新物品。  
- 满足上述条件后进化，匹配当前强度。跨档间距以 §9.1 的 `Stage` 为准（如鲤鱼王 1 → 暴鲤龙 9）。  
- 可进化时：服务端校验 → 玩家确认 UI（进度上升或升级越过 `BandMin` 时可弹）→ 替换。也可用 `/henshin evolve` 在条件已满足时补弹。  
- **不变之石**（A24）戴着即阻止进化（未变身也生效）。

**替换范围：**

| 位置 | 自动进化（条件满足时） |
|------|----------|
| 背包、热键栏、鼠标悬空物品 | 是（经确认 UI） |
| 银行、保险箱、世界箱子、地上掉落、商店 | 否（可手动进化） |

流程：服务端校验双条件 → 玩家确认 UI → 替换物品类型（**继承前缀、收藏、Level、Xp**）→ 同步。失败则不改物品。

### 4.4 开局御三家

世界创建后（或玩家首次进入该世界时），发放：

- **小火龙之力**  
- **杰尼龟之力**

### 4.6 等级、经验与攻防（v1.4）

数值真源表：`docs/balance-stats.md`。本节为产品规则；数字冲突时以 balance-stats 为准。

#### 4.6.1 归属与存档

- 等级 / 经验绑定**物品实例**（两只喷火龙可不同级）。  
- 字段：`Level`（1～100）、`Xp`（当前级内进度）。  
- 进化时完整拷贝到新形态物品。  
- 新生成物品：`Level = BandMin[form.Stage]`（传说掉落不从 1 级爬）；`Xp = 0`。  
- 联机：服务端权威；持握同步须含 level、xp、energy。

#### 4.6.2 等级带（连续等级 + 阶段硬顶）

| ProgressStage | 等级带 | 段长 |
|---:|:---|---:|
| 1 | 1–5 | 5 |
| 2 | 6–11 | 6 |
| 3 | 12–18 | 7 |
| 4 | 19–25 | 7 |
| 5 | 26–33 | 8 |
| 6 | 34–42 | 9 |
| 7 | 43–51 | 9 |
| 8 | 52–61 | 10 |
| 9 | 62–70 | 9 |
| 10 | 71–80 | 10 |
| 11 | 81–90 | 10 |
| 12 | 91–100 | 10 |

- `GetProgressStage() = S` 时，该物品 `Level` 最高为 `BandMax[S]`。  
- 卡顶：经验截断到「升下级所需 − 1」，UI 显示「阶段上限」。  
- 世界阶段上升**不**自动加等级，只抬高硬顶。  
- **不做** Boss 首杀额外经验；**不做**卡顶/满级经验溢出转能量。

#### 4.6.3 升级所需经验

当前等级 `L` 升到 `L+1`：

```
若 L <= 50:  BaseExpNeeded = 50 + 15 * (L - 1)
若 L > 50:   BaseExpNeeded = 785 + 40 * (L - 50) + 0.8 * (L - 50)^2.2
StageXpScale(S) = 1 + (S - 1) * 299 / 11     // 档 1 = 1，档 12 = 300
ExpNeeded(L) = round(BaseExpNeeded(L) * StageXpScale(BandForLevel(L)))
```

需求跟**物品等级带**放大，不跟世界档。满级 100 后不再获得经验。

#### 4.6.4 经验获取

- **小怪 / 非 Boss：** 持握本模之力且击杀归属为本模招式（含弹幕）时，`XP += Random(round(1×Scale)..round(3×Scale))`，`Scale = StageXpScale(GetProgressStage())`。档 1 为 1～3，档 12 为 300～900。  
- **Boss：** 动态公式得出 `BossXP` 后再 `× StageXpScale(世界档)`（与小怪同一系数，相对比例不变）；多节 Boss 仅在最终击杀结算一次：

```
lifeTerm = (max(lifeMax,1) / 2000)^0.45
defTerm  = 1 + defense / 100
stageMul = 0.75 + 0.12 * GetProgressStage()
BossXP   = Clamp(round(14 * lifeTerm * defTerm * stageMul), StageMin, StageMax)
```

史莱姆王锚点约 **20 XP**（×世界 Scale 前）；各档夹子与校准见 `docs/balance-stats.md`。个别异常 Boss 允许白名单覆写。世界字提示：击杀处 `EXP +X`，玩家处连升连弹 `LEVEL UP!`，Boss 更大并描边闪光。

#### 4.6.5 攻击与防御

旧 `StageDamage = 8 + stage * 6` **废弃**。阶段基准对齐灾厄大修比目鱼的**有效 DPS 成长形状**（只读参考，无运行时依赖），再按本模「标准技 UseTime 20 ≈ 3 APS、倍率 1.0」反推面板。

```
S = BandForLevel(Level)   // 攻防插值用物品等级所在带；世界 GetProgressStage() 只做等级硬顶与进化进度条件
t = (Level - BandMin[S]) / max(1, BandMax[S] - BandMin[S])
tw = t ^ LevelCurve[S]
StageAttack  = lerp(MidAtk[S]*FloorMult[S], MidAtk[S]*CeilMult[S], tw)
StageDefense = lerp(MidDef[S]*FloorMult[S], MidDef[S]*CeilMult[S], tw)

AttackMod  = Clamp(max(种族攻击, 种族特攻) / 100, 0.50, 1.45)
DefenseMod = Clamp(((种族防御 + 种族特防) / 2) / 100, 0.55, 1.50)

FinalAttack  = max(1, round(StageAttack * AttackMod * HenshinDamageFactor))
FinalDefense = max(0, round(StageDefense * DefenseMod))
```

种族值以第九世代为准（非超级进化）；36 形态 Mod 全表见 `docs/balance-stats.md`。段内升级收益刻意加大（约 +55%～+90% 视阶段），用于体感成长；更大跳变仍来自**推进阶段 / 进化新形态与新技能**。

## 12. 技术约束

1. 变身用可清理的玩家标志 / Buff；退出时只清除本模授予的效果，不误删原版或灾厄增益。  
2. 切换另一种之力时：先完整退出，再进入。  
3. 水下呼吸、熔岩免疫等优先用 `ModPlayer` 标志模拟。  
4. 进化与进度校验必须在服务端完成。  
5. 伤害按第 2.6 节接入灾厄，并做职业叠乘回归测试。  
6. 改地形必须服务端权威。  
7. 显示名与资源路径可热替换，避免写死无法换皮。  
8. 依赖版本：与当前稳定灾厄所要求的 tModLoader 一致；开工时在工程内钉死版本号。  
9. 特效资产遵守 §1.5；宝可梦外观资源遵守 §1.4。

## 14. 验收清单

1. 持握之力：外观、被动、技能1/2、能量大招、变身饰品同时生效；坐骑不可用。  
2. 取消持握：上述本模效果同 tick 消失；坐骑恢复可用。  
3. 开局可获得御三家三件之力。  
4. 进化符合双条件（进度档 + 等级进入下一形态 `BandMin`）、替换范围与前缀/`Level`/`Xp` 继承。  
5. 各档登场以 §9.2 为准；同档互竞可感知。  
6. 持握被动与属性生存/机动按第 2.5 / 3.2 节工作。  
7. 后期存在超梦、洛奇亚、烈空坐等更强传说向之力。  
8. 联机下形态、能量、**等级/经验**与伤害无明显分歧。  
9. 地鼠线改地形遵守 §7 预算与黑名单。  
10. DPS 落在对标区间内（含等级段底/段顶抽检）。  
11. 招式观感来自原版/灾厄/大修复用或改参（§1.5）。  
12. 变身 Overlay 使用的宝可梦图来自约定图鉴来源（或可替换路径），而非自制特效图集。  
13. 物品描述含获取/进化条件（含等级要求）；进度档提升有提示（史莱姆王 ≠ 史莱姆神）。  
14. 变身时盔甲防御被形态防御取代，饰品防御仍生效。  
15. 不够等级时即使已击败对应 Boss，也不得进化。
