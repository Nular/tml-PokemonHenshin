## 3. 经验获取

### 3.1 小怪

`XP += Random.Shared 均匀 1..3`（持握 + 本模招式击杀）。

### 3.2 Boss 动态公式

```
lifeTerm = pow(max(npc.lifeMax, 1) / 2000.0, 0.45)
defTerm  = 1.0 + npc.defense / 100.0
stageMul = 0.75 + 0.12 * GetProgressStage()
raw      = 14.0 * lifeTerm * defTerm * stageMul
BossXP   = Clamp(round(raw), BossXpMin[S], BossXpMax[S])
```

判定：`npc.boss` 或灾厄/大修 Boss 启发式；多节 Boss **仅最终击杀一次**。

```
t  = (Level - BandMin[S]) / max(1, BandMax[S] - BandMin[S])
tw = pow(t, LevelCurve[S])
StageAttack  = lerp(MidAtk*Floor×, MidAtk*Ceil×, tw)
StageDefense = lerp(MidDef*Floor×, MidDef*Ceil×, tw)   // 同 Floor×/Ceil×
FinalAttack  = max(1, round(StageAttack * AttackMod * HenshinDamageFactor))
FinalDefense = max(0, round(StageDefense * DefenseMod))
```

**废弃：** `FormItemUtil.StageDamage = 8 + stage * 6`。

## 7. 招式数值门禁（MoveRefRate）

`MoveRefRate` 是**参考预算**，不是铁律。每个招式表现形式不同；实装时结合命中难易、攻击距离、风险承担做柔性调整，最终以同档 DPS 窗（requirements §2.6）与手感验收为准。

```
MoveRefRate = (60 / UseTime) * DamageMultiplier * ExpectedHitsPerRelease
```

| 类型 | 参考目标（可浮动） |
|------|-------------------|
| Standard | MoveRefRate 约 **0.85～1.15** |
| HighFrequency（UseTime≤16） | 约 ≤ **1.25**；EnergyGainFactor≤0.35 |
| MultiHit（一次≥3 段） | 总预算约 0.85～1.25；EnergyGainFactor≤0.25 |
| WideAoE（半径≥8 或超大锥） | 相对标准约 ×**0.75～0.85**；Factor≤0.45 |
| Ultimate | 不进持续 DPS 主预算；爆发窗约标准 3 秒 DPS 的 **2.2～3.5×**；同名异槽必须分列倍率 |

### 7.0 柔性平衡原则（优先于机械套公式）

1. **段数谨慎调整：** 段数同时影响伤害与手感/节奏；优先调 **单段 `DamageMultiplier` / `EnergyGainFactor`**，非必要不砍段数、不盲目加段。
2. **按表现形式个案处理：** 锥扫、连射、落点、突进、持续束等不可套同一套「理想段数」。
3. **风险 / 命中难度补偿（倍率可偏离参考窗）：**
   - **短距近战 / 贴身高风险** → 单段或总预算可**偏高**（承担走位与受伤风险）。
   - **追踪远程 / 易命中 / 安全距离** → 单段或总预算宜**偏低**。
   - **大范围、低操作门槛清图** → 偏低 + 充能 Factor 从严。
   - **窄弹道、短窗、需预判** → 可略抬倍率。
4. 面板抬高后须防止高频/多段**超模**，但手段是「压单段或充能」，不是「为过公式而改段数」。
