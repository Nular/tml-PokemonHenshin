# Assets/Sounds 来源

全部为 **self-made, procedural**（自制，程序化合成）。没有下载、采样或录音；没有任何 Pokemon / Nintendo / 原版 Terraria 音频。

- 生成器：`Assets/TEMP_ASSETS/fx-feel/sfx-gen/gen.py`（目录与试听页）+ `recipes6.py`（R6 配方）+ `dsp.py`（numpy 合成工具：正弦/FM/限带锯齿与方波、模态谐振、粉噪/褐噪、短瞬态、碎石叮、扫频、FFT 与时变 SVF 滤波、气泡、平滑限幅、暗房间混响、降采样）。该目录被 gitignore，只在本地。
- 格式：单声道 PCM 16-bit WAV，**22.05 kHz**，采样峰值 ≤ -3 dBFS，真峰值（4 倍过采样）≤ -1 dBTP，首尾淡入淡出（无爆音）。52 个共 766,544 字节。
- 每个文件有固定随机种子，重跑得到相同结果：`python Assets/TEMP_ASSETS/fx-feel/sfx-gen/gen.py`。44.1 kHz 合成，同一步降到 22.05 kHz（255 抽头 Blackman sinc，10 kHz 低通 + 隔点取样）并定峰值。
- R5（2026-11-27）：饱和只作用于 200 Hz 以上，平滑限幅补响度。报告 `Assets/TEMP_ASSETS/fx-feel/r5-sfx-clip.md`，R4 备份 `r5-sfx-bak/`。
- R6（2026-11-27）：用户觉得除 SteelHit / PsyHit 外都有「风吹麦 / 滋滋」感。诊断出难听组 50-88 % 是宽带噪声（A 计权），干净组 < 12 %。按干净组路线重做 48 个：主体用有音高的成分（正弦、模态、FM、限带锯齿），噪声只做 < 30 ms 瞬态、粉/褐噪或 Q≥4 窄带，全部不饱和，混响不进低频，6 kHz 左右高切。SteelHit1/2、PsyHit1/2 字节不变。报告 `Assets/TEMP_ASSETS/fx-feel/r6-sfx-clean.md`，R5 备份 `r6-sfx-bak/`。
- 代码入口：`Content/Combat/Moves/HenshinSfx.cs`（`SfxKey` → `SoundStyle`）。
